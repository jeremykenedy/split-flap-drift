# Changelog

## 1.0.0

- Initial release of the animated Split-Flap Drift clock for Android API 23 and newer.
- Added adjustable time format, palette, flip pace, date, seconds, lighting, scale, and brightness.
- Added remote-operated settings, per-setting random choices, and a local settings provider.
- Added a checksum-verifying installer with restore and uninstall support.
- Runtime makes no network requests and includes no ads, analytics, tracking, or reporting.
